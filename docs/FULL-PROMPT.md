# HavenOS – Full App Building Prompt

Use this prompt with the automated AI that is building the app.

---

```
Build a complete Android launcher application called "HavenOS".

### Product Vision
HavenOS is a tablet-first Android launcher designed primarily for 10–11 inch tablets in landscape orientation. 
It focuses on being premium, calm, highly customizable, and wallpaper-first. 
It is fully free, with no ads, no accounts, and no tracking.

There are no named style presets (no Futuristic, Retro, Classy, Soft, etc.).

### Core Features

1. Home Screen
   - Horizontal page swiping only
   - Widgets and cards are semi-transparent / translucent so the system wallpaper remains the main visual
   - Support both Smart Grid and Free Canvas placement
   - Users can freely move, resize, and arrange apps, folders, and widgets

2. Customization System
   - Long-press empty space to enter Edit Mode
   - Long-press + drag to move apps and widgets
   - Drop one app on another to create a folder
   - Long-press widgets to resize them with handles
   - Add widgets from a widget picker
   - Full control over:
     - Density (Sparse / Medium / Dense)
     - Transparency and blur strength
     - Corner radius
     - Icon size
     - Dock style
     - Folder style
     - Accent color
     - Grid size and margins
   - Snap-to-grid can be turned off for true free placement

3. App Drawer
   - Fast search
   - Recent apps
   - Clean grid with alphabet index

4. Design Language
   - Android-native
   - Semi-transparent dark cards so wallpaper shows through clearly
   - Soft shadows and refined spacing
   - Calm and premium feel

### Technical Requirements
- Target: Android tablets (landscape)
- Smooth 60/120fps animations
- Lightweight and battery efficient
- Fully offline
- Clean modern codebase

### Goal
Create a refined, wallpaper-first, fully manual-customizable tablet launcher that feels better and more flexible than stock Android launchers.
