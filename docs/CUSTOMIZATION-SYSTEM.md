# HavenOS – Customization System (Updated)

HavenOS no longer uses named style presets (Futuristic, Retro, Classy, Soft, Minimal, Premium, etc.).  
All visual styling is now fully manual and under the user’s control.

---

## 1. Core Customization Philosophy

- No preset “Looks”
- Users directly control every visual aspect
- A simple **Density** setting remains (Sparse / Medium / Dense) to quickly change overall spacing and size
- Everything else (transparency, blur, corner radius, icon size, dock style, colors, etc.) is controlled individually

---

## 2. Basic Interaction Model (Same as Stock Android)

- **Long-press** on empty space → Enter Edit Mode
- **Long-press** on an app icon → Show actions + allow dragging
- **Long-press** on a widget → Show resize handles + remove option
- **Drag and drop** to move apps, folders, and widgets
- **Drag edges / handles** to resize widgets and folders

---

## 3. Moving Apps & Icons

- Long-press any app → it lifts with elevation
- Drag freely across the page or to the edge to change pages
- Drop on empty space to place
- Drop on another app to create a folder
- Drop on an existing folder to add it
- Optional Snap-to-Grid (can be turned off for true free-canvas)

---

## 4. Folders

- Create: Drag one app onto another
- Open, rename, rearrange icons inside
- Drag icons out to remove them
- Folders can be resized
- Folder style (background opacity, shape, preview style) is controlled manually in Settings

---

## 5. Widgets

- Add: Long-press home screen → Widgets
- Resize: Long-press widget → drag the handles
- Move: Long-press + drag
- Remove: Long-press → Remove, or drag to the remove zone
- Widgets support free placement and resizing

---

## 6. Free-Canvas + Smart Grid

Two modes:

- **Smart Grid** (default) – elements snap to grid
- **Free Canvas** – turn off snapping for complete freedom

Users can switch anytime in Settings.

---

## 7. What Users Can Customize Manually

Since there are no presets, users control:

- Overall Density (Sparse / Medium / Dense)
- Widget & card transparency / blur strength
- Corner radius
- Icon size
- Dock style and height
- Folder style
- Accent color
- Grid size
- Page margins and padding
- Animation intensity

All of these are available in Settings → Personalization.

---

## 8. Edit Mode

Long-press empty space to enter Edit Mode:

- Home screen zooms out slightly
- Options appear: Add Widget, Add Page, Wallpaper, Personalization, Settings
- Freely drag and resize everything
- Tap Done or Back to exit

---

## 9. Summary of Actions

| Action                      | How to do it                          |
|----------------------------|---------------------------------------|
| Move app/icon              | Long-press + drag                     |
| Create folder              | Drag app onto another app             |
| Resize widget / folder     | Long-press → drag handles             |
| Add widget                 | Long-press home → Widgets             |
| Remove item                | Long-press → Remove                   |
| Change density             | Settings → Density                    |
| Change transparency/blur   | Settings → Personalization            |
| Free placement             | Disable Snap-to-Grid                  |

---

This system keeps the familiar Android feel while giving users complete control without any locked presets.
